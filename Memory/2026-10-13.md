# 2026-10-13 — Daily Log

## Telegram Bot UI/UX & Burmese Copywriting Modernization

**Context:** The Telegram storefront bot had sensory-overload issues caused by legacy animated custom emojis on every heading and inline button, causing excessive visual flickering ("ဘလင်းဘလင်း"). In addition, verbose message copy with redundant explanations and English phrases made screens cluttered and lengthy.

**Changes:**
1. **Telegram Premium Outline Emojis (`packages/shared/src/emoji.ts`):**
   - Replaced animated emoji IDs in `BOT_EMOJIS` with 17 Telegram Premium outline/monochrome custom emoji IDs (Store, Profile, Wallet, Orders, Chat, Channel, Back, Home, Buy Now, Plus, Minus, Check, Cancel, Key, Receipt, Alert, MMQR).
   - Preserved verified bank logos (KBZPay, WavePay, UABPay, AYAPay).

2. **Burmese Copywriting Refinement (`apps/bot/src/formatters/messages.ts`):**
   - Condensed message lengths by ~60% across `/start`, categories, products, product detail card, profile, wallet, deficit top-up, order confirmation, and instant delivery.
   - Replaced mixed English terms with polite, natural Burmese phrases.
   - Formatted product detail pricing and stock in 3 clean lines (`စျေးနှုန်း`, `လက်ကျန်`, `အရေအတွက် • စုစုပေါင်း`).
   - Standardized delivery notification header to `ဝယ်ယူမှု အောင်မြင်ပါသည်`.

3. **Stepper & Keyboard Controls (`apps/bot/src/keyboards/store.keyboards.ts`):**
   - Fixed stepper glitches: Minus button no longer swaps to a red cross (`❌`) when disabled at qty 1; counter button renders plain numeric text `${quantity}` without stray bottle icons; plus button uses clean outline icon.
   - Cleaned amount presets (`5,000 Ks`, `10,000 Ks`, etc.) to clean text-only buttons without duplicate icons.
   - Standardized navigation labels to `နောက်သို့` and `ပင်မစာမျက်နှာ`.
   - Updated custom quantity button to `စိတ်ကြိုက် အရေအတွက်` and prompt to `စိတ်ကြိုက် အရေအတွက် သတ်မှတ်ခြင်း:`.

4. **Compact Presets & Icon Refinements:**
   - Removed `30` and `50` presets from product detail card, retaining a single compact row `[ 1 ] [ 5 ] [ 10 ] [ 20 ]`.
   - Updated greeting copy in `formatStartMessage` to `Premium AI Tools နှင့် Digital Accounts များကို တစ်နေရာထဲတွင် 24/7 ရနိုင်ပါပြီ ဗျာ။`.
   - Added `BOT_EMOJIS.EDIT` (`5985774024968379294`) to custom quantity and custom top-up buttons.
   - Restored `BOT_EMOJIS.MMQR` (`5422814644093868925`) for MMQR invoice messages and payment method buttons.
   - Added `BOT_EMOJIS.FIRE` (`5303040337059543238`) on the popular `10,000 Ks` wallet top-up button.
   - Applied pending DB migrations (0010-0014) to resolve MMPay columns query error in PostgreSQL.
   - Removed all `reply_parameters` across commands (`/start`, `/orders`, `/wallet`, `/profile`, `/deposit`, `/help`) and text handlers, eliminating gray quote boxes for a clean DigitalCore-style UI.
   - Cleaned `/help` command: simplified caption to 2 polite lines and removed `@ArenaStoreSupport_Bot` handle clutter from both message body and inline button.
   - Added `BOT_EMOJIS.PROHIBITED` (`5872829476143894491`) on quantity presets exceeding current product stock (e.g. `[ 🚫 20 ]` when stock is 13).
   - Updated `qty_max_` callback query to display a friendly top toast notification (`Stock ${stock} ခုထိပဲ ရနိုင်ပါတော့မယ်ဗျာ`) instead of a blocking popup dialog.
   - Implemented 2-step inline keyboard confirmation for MMQR & Manual top-up cancellations (prevents accidental cancellation while scanning/transferring).
   - Added `/products` (`/store`, `/shop`) command handler and registered complete command list in Telegram menu: `/start`, `/products`, `/orders`, `/wallet`, `/profile`, `/help`.
