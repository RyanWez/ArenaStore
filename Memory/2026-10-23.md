# 2026-10-23 — Daily Engineering Log

## Web Storefront Planning, Architecture & Design System Specification

### 1. Scope & Objective
Formulate the complete technical architecture and implementation roadmap for expanding Arena Store with a dedicated web storefront (`apps/web` at `arena.ryanwez.com`) and Telegram Mini App, providing full feature parity with `@arena/bot` while maintaining 100% data and money safety.

### 2. Key Decisions & Agreements
- **Unified Identity & Wallet:** Web uses existing Telegram identity. Zero separate user accounts; `telegramId` links all wallet balances, ledger entries, and orders.
- **Dual Authentication Engine:**
  1. *W3K-Style 4-Digit Bot Handshake:* For external browsers (PC/phone Chrome/Safari), web generates 4-digit challenge, user clicks deep link `t.me/ArenaStoreBot?start=login_<ticketId>`, bot displays 2x2 inline matching keyboard with device/IP security metadata, user taps matching digit, web instantly logs in via SSE.
  2. *Telegram Mini App Instant Bypass:* Inside Telegram WebApp, validates `initData` HMAC-SHA256 signature for 0-second auto-login.
- **2026 Flat Monolithic Design System:** Strictly zero gradients and zero purple. Monolithic deep carbon (`#08090B`), flat matte card surfaces (`#101216`), 1px crisp borders (`#1F232D`), and solid Signal Orange (`#FF5A1F`) accent.
- **Mobile-First Layout:**
  - Mobile: 2-column bento, 3D card deck slider with touch swipe, frosted bottom navigation bar (`Home`, `Products`, `Orders`, `Profile`), full-width virtual black titanium member card with gold EMV chip.
  - Desktop: 4-column bento, left navigation rail, spacious header with ⌘K search.
- **Zero Duplication Core Engine (`@arena/core`):** Extraction of order, catalog, and referral business logic from `apps/bot` into shared package to be consumed by both `apps/bot` and `apps/api`.
- **Concurrency & Safety:** PostgreSQL advisory lock (`pg_try_advisory_xact_lock`), atomic conditional debit (`balance_mmk >= totalMmk`), paired atomic ledger insertion, AES-256-GCM encrypted credentials vault.
