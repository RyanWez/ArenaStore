Every endpoint except

3. Conventions

Idempotency.
Sending the same
externalOrderId
again returns the
same
order with
"duplicate": true
— you are never charged twice, even after a
network timeout. Always retry with the same id.
Delivery.
delivery.lines[]
holds exactly
quantity
items — one account/key per line. Store them on your side
immediately; the same content can also be re-read via
GET /orders/{id}
.
Atomic billing.
Wallet charge and stock
reservation are one conditional SQL transaction. If delivery fails, the order
is rolled back and your wallet refunded automatically — no half-orders.

9. Hosting the API (for the store owner)
The Partner API is a
separate process
next to the bot, using the same
database. Telegram does
not
give you a public URL — you must run it on
your own VPS / server. A domain is optional — the server's public IP works.
pip install -r requirements.txt
python api_server.py          # listens on 0.0.0.0:4153
Keep both processes alive (systemd, screen, pm2 or Docker):
# /etc/systemd/system/xpro-api.service
[Service]
WorkingDirectory=/root/xpro
ExecStart=/usr/bin/python3 api_server.py
Restart=always
Then put Nginx/Caddy in front for HTTPS:
location /api/ {
    proxy_pass http://127.0.0.1:4153;
    proxy_set_header Host $host;
}
No domain?
Nothing to set — the bot auto-detects your server's public
IP and uses
http://<your-ip>:4153
as the Base URL. Just open the
port in your firewall (
ufw allow 8080
). Only set
API_PUBLIC_URL
if you later buy a domain.
.env
values:
# API_PUBLIC_URL=https://yourdomain.com   # optional, only with a domain
# SERVER_IP=123.45.67.89                  # optional, if auto-detect fails
API_HOST=0.0.0.0
API_PORT=4153
API_KEY_SECRET=<long random string — never change after keys exist>
API_MAX_KEYS=3
The IP setup works fine, but traffic is plain HTTP.
When you can, buy a cheap domain + free Let's Encrypt certificate and switch to
API_PUBLIC_URL=https://yourdomain.com
.
10. FAQ & safety
Do I need my own server?
Yes. The bot and the API both run on your VPS. The bot works through
Telegram's long-polling (no URL needed), but resellers must call the API over
HTTP, so the API needs a reachable address.
Can the bot and API run together?
Yes — SQLite runs in WAL mode with busy timeouts, so both processes can read
and write at the same time without double-selling.
What happens if my key leaks?
Open
API → My Keys → ♻️ Regenerate
(or 🗑 Revoke). The old key stops
working instantly.
How do I get paid?
Resellers pre-fund their bot wallet; every API order deducts from it
automatically at the same price shown in the bot.
