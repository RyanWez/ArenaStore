DigitalCore API

A high-speed, wholesale REST API for automated stock synchronization, instant key delivery, and balance-backed purchasing with sub-millisecond execution. Built for resellers, automated bots, and enterprise integrations.

Base URL https://digitalcore.top

Authentication

Every request to the user API requires your unique personal API Key.

How to Get Your API Key
API keys cannot be generated directly on this website.
Your API key is permanently linked to your Telegram account and Telegram bot balance. To get your API key:
  1. Open our official Telegram Bot: @DCoreStoreBot
  2. Navigate to ⚙️ Reseller API in the main menu.
  3. Your personal Api-Key is displayed there. Copy it and keep it secret.
All purchases made through the API will deduct funds from your Telegram bot balance and deliver keys directly to your order response.
Required Request Header

Pass your API key in the Api-Key header with every request (also accepts X-Api-Key or Authorization: Bearer <key>):

HTTP Header 
Api-Key: a1b2c3d4-e5f6-7890-abcd-ef1234567890

GET /api/user/products & /api/user/product
Retrieve the complete catalog of active products or query detailed pricing and stock for an individual product by passing its id query parameter (slug or numeric ID).
Query Parameters
Parameter Endpoint Type Required Description
— /api/user/products — None Returns a list of all publicly available products with stock, base prices, and wholesale discount tiers.
id /api/user/product string Required Product slug (e.g. gemini_pro_18_months) or numeric ID. Returns a single product object. Returns 404 if not found or Hidden.

GET /api/user/me
Returns account summary for the authenticated user, including current available Telegram bot balance and total count of completed orders.
Request Example
curl 
curl -s -H "Api-Key: YOUR_API_KEY" \
  https://digitalcore.top/api/user/me
Response Example (200 OK)
JSON 
{
  "balance": 142.0,
  "total_orders": "30"
}
POST /api/user/buy
Instantly purchases products using your Telegram bot account balance.

Zero Race Condition Guarantee: Uses database row-locking and atomic transactional key reservation. If stock is insufficient or balance is low, the transaction is fully rolled back, preventing double-spending and overselling under high concurrency.
Parameters (URL Query or JSON Body)
Parameter Type Required Description
id string Required Target product slug (e.g. gemini_pro_18_months) or numeric ID.
count integer Optional Quantity to purchase (default: 1, max: 1000). Tier pricing applies automatically.
Request Example (Query Parameters)
curl (query string) 
curl -s -X POST -H "Api-Key: YOUR_API_KEY" \
  "https://digitalcore.top/api/user/buy?id=gemini_pro_18_months&count=1"
Request Example (JSON Body)
curl (JSON payload) 
curl -s -X POST \
  -H "Api-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"id": "gemini_pro_18_months", "count": 1}' \
  https://digitalcore.top/api/user/buy
Response Example (200 OK Success)
JSON 
{
  "success": true,
  "order_id": "ORD-3232432",
  "view_url": "https://digitalcore.top/order?number=a2de1869-3524-41d8-1bc2-f0722d73e071",
  "total_amount": 0.55,
  "quantity": 1,
  "items": [
    "https://g.co/gemini/share/sample_activation_token_123"
  ]
}
Response Example (400 Out of Stock / Insufficient Balance)
JSON Error 
{
  "success": false,
  "msg": "OUT_OF_STOCK"
}
GET /api/user/history
Returns your paginated order history (50 orders per page), sorted chronologically from newest to oldest.
Query Parameters
Parameter Type Required Description
page integer Optional Page number (default: 1). Page 1 returns items 0–50, page 2 returns 50–100, etc.
Request Example

curl -s -H "Api-Key: YOUR_API_KEY" \
  "https://digitalcore.top/api/user/history?page=1"

GET /api/user/order
Fetches single order details and delivered key items. Access is strictly verified against your authenticated account (you can only view your own orders).
Query Parameters
Parameter Type Required Description
id string Required Order number (e.g. ORD-3232432).
Request Example
curl 
curl -s -H "Api-Key: YOUR_API_KEY" \
  "https://digitalcore.top/api/user/order?id=ORD-3232432"
Response Example (200 OK)
JSON 
{
  "order_id": "ORD-3232432",

Error Codes Reference

Standard error codes returned by the API inside {"success": false, "msg": "..."}:

Status Code Error Message (msg) Description
401 Unauthorized MISSING_API_KEY The Api-Key header was omitted from the request.
401 Unauthorized INVALID_API_KEY The provided API key is invalid or does not match any registered account.
400 Bad Request INSUFFICIENT_BALANCE Your Telegram bot balance is lower than the order total amount. Top up in bot first.
400 Bad Request OUT_OF_STOCK Not enough keys available in stock to fulfill the requested quantity.
400 Bad Request ID_REQUIRED The id parameter is missing from the request.
400 Bad Request INVALID_COUNT The count quantity must be a positive integer >= 1.
400 Bad Request MAX_COUNT_EXCEEDED Maximum purchase volume is 1,000 items per single order request.
404 Not Found PRODUCT_NOT_FOUND Product does not exist or has been hidden by administration.
404 Not Found ORDER_NOT_FOUND Order number was not found or belongs to another user account.
