# Arena Store — Admin Dashboard

Built with **Nuxt 3**, **Tailwind CSS**, and **PrimeVue (v4)** using the Aura theme preset.

## Setup & Scripts

```bash
# Run local dev server
pnpm dev

# Build for production
pnpm build

# Preview production build
pnpm preview
```

## Features (Planned for Phase 3)
- Product & Category Management with PrimeVue `DataTable` (filters, sorting, pagination, and stock status).
- Live MMK Retail Pricing & Profit Margin adjustments.
- Payment Slip Review Drawer (zoomable KPay/WavePay receipt, One-Click Approve & Auto-Deliver, or Reject).
- Upstream Supplier Wallet Balance & Health Monitoring Widget ($1.00 USD live display).
- Dark Mode by default.
